## 📖 Sobre o Projeto

Este portfólio foi criado como parte da minha jornada no **Desenvolvimento de Sistemas** e representa meus primeiros passos no mundo do **Front-end**. O objetivo é apresentar:

- Minha trajetória como estudante de Tecnologia
- Aba para projetos futuros
- Tecnologias que estou aprendendo atualmente
- Links para contato profissional (PROCURO ESTÁGIO!)

### Passo a passo

1. **Clone o repositório**
```bash
git clone https://github.com/emanuelxbt/portfolio_frontend.git
Acesse a pasta
bash
cd portfolio_frontend
Abra o arquivo HTML
bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html

📱 Responsividade

O portfólio se adapta perfeitamente a diferentes tamanhos de tela:

Dispositivo	Largura	Comportamento
📱 Smartphone	< 768px	Layout em coluna, menu reduzido
📟 Tablet	768px - 1024px	Layout adaptativo
💻 Desktop	> 1024px	Layout completo com sidebar
